Clean Code skills for opencode

Language-routed Clean Code reference skills, served as a remote skill index.

Install

Add this to ~/.config/opencode/opencode.json. Skills update themselves on the next opencode start — there is nothing to reinstall.

{
  "skills": {
    "urls": ["https://korsicheg.github.io/opencode-marketplace/skills/"]
  }
}
